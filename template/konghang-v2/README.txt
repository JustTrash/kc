港恒国际官网 V2.2 整改版

技术：纯 HTML + CSS + JavaScript，无框架、无第三方依赖，可直接部署到 GitHub Pages 或普通虚拟主机。

文件：
- index.html：首页结构与对外文案
- styles.css：品牌视觉、动画与响应式样式
- script.js：移动端菜单、滚动导航、案例筛选与项目自测

本版已按《港恒国际官网建设整改建议》重构：
1. 首屏左侧保持身份、升学与家庭发展定位，右侧规划卡片展示身份、教育、家庭与后续四个方向。
2. 信息架构由“项目目录”调整为“客户问题 + 判断能力”。
3. 增加企业主专项、技术专才、Top-up 路径边界、家庭规划与长期发展。
4. 将客户版案例册的 7 个匿名案例完整适配到官网，每例展示客户情况、关键难点、规划方向与阶段价值；不公开内部 SOP、材料逻辑或证据链方法。
5. 增加案例分类、移动端固定 CTA 与电话／微信直接联系入口。
6. 复核 pdf 目录 6 份资料，将移民宣传册的路径适配与长期规划、升学宣传册的阶段选择与管理类课程、技术专才培训手册中可公开的 GEP/专才/技术专才区别，以及 Top-up 培训手册中可公开的四类衔接方式补入相应页面板块。
7. 补入 V1 的六项“项目介绍”：高才、优才、输入内地人才、投资者、留学进修、续签。项目区沿用 V1 的图片、柔和渐变背景、分类标签、卡片点击弹窗及微信咨询二维码交互；V1 中过于绝对或随政策变化的固定条件未原样复制，详情文案保留官方核对链接。
8. 增加一分钟路径自测：访客可多选个人背景，在弹窗中同时查看高才 A/B/C、优才、专才、投资及 VTC/Top-up 等初步方向与现有微信二维码。自测结果不等于申请资格或录取承诺。

PDF 内容适配原则：
- 公司简介：主体名称、服务定位和工作原则放在首屏、关于港恒及服务旅程。
- 移民宣传册：客户适用情境、主要身份项目和家庭长期发展放在身份规划。
- 升学宣传册：本科、副学位/VTC、衔接本科、硕士/管理方向放在教育规划。
- 客户版案例精选：7 个匿名案例放在成功案例；保留个案限制说明。
- 两本员工培训手册：只呈现客户需要理解的项目区别、课程类型和风险边界；内部 SOP、话术、审核方法、材料清单与员工培训内容不对外展示。
- 政策金额、名额、院校招生条件、课程学制、学费及签证资格等变动信息没有直接照搬 PDF，页面提供官方核对入口，发布前仍须再次复核。

联系入口说明：
- 当前静态版不设置个人信息收集表单；访客可直接拨打热线或扫描现有微信二维码联系顾问。
- 如后续需要线上提交咨询信息，应先接入可靠的接收服务并同步完善隐私说明。

5. 政策、院校、费用和资格文案上线前按最新官方资料复核。
